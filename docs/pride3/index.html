Rules

大会ルール

ルールを開く（1vs1・アイテム・不戦敗）
形式
  • 1vs1の完全勝ち抜き制。負けたらそこで終了
  • 勝敗はバトルスコアが高い方が勝ち
  • 招待制。今回ご案内した方が参加対象です
  • 何回戦やるかはエントリー人数で決まる（決勝は11/4固定）
アイテム
  • グローブは1試合2個まで
  • それ以外のアイテムは制限なし
試合の進め方
  • 試合はすべて22:00〜スタート
  • 開始5分を過ぎて枠が立たない場合は不戦敗になります
  • 勝った方は結果のスクショをLINEで送ってください
  • 試合の間は中2日。ここが作戦会議とアイテム貯めの時間になります
  • 日程の個別調整はできません。勝ち進んだ場合に候補の夜すべて配信できる方だけご参加ください
賞
  • 優勝・準優勝のおふたりにトロフィーをお渡しします
